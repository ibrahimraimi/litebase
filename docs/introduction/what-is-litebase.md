# What is Litebase

Litebase is an open source platform that provides a developer-first control plane for SQLite. It is designed to let you run, manage, and host SQLite databases with modern infrastructure practices, utilizing a standard HTTP API for secure access.

By abstracting away the complex file-system level semantics of SQLite, Litebase makes it easy to collaborate across teams, provision databases programmatically, and interact with data securely via REST queries.
